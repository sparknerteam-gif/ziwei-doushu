# Leads Directory

Each lead gets one `.md` file. Save them here after downloading from the dashboard.

## File naming
`YYYY-MM-DD_username.md` (e.g., `2026-08-12_u_sparknerteam.md`)

## Workflow

1. Lead submits form → appears in dashboard
2. Click **💾 Save Lead File** → saves to this folder
3. Open the file, copy the calibration prompt block
4. Paste into Claude → kismet-engine calibrates
5. Claude outputs Calibration Report + DM Script → paste back into the file
6. Send DM script to lead via Reddit/Instagram/Email
7. Log follow-ups in the file

## Template

Each lead file has these sections:
- **Raw Data** — original form submission
- **Calibration Prompt** — ready to paste into Claude
- **Reading Output** — paste Claude's response here
- **Follow-up Log** — track DMs, replies, conversions
